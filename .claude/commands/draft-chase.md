---
description: Draft a polite chase to the builder or engineer for drawings out for approval, tied to the site date that depends on them.
---

1. Run `npm run steel -- holds --json` and `npm run steel -- sequences --json`.
2. For the project asked about, write a short note to the builder's contact (from `npm run steel -- project <code>`): which drawings, issued when, which sequence and site date depend on them, and the latest approval date that still makes that site date.
3. Save it to `drafts/chase-<project>-<date>.md`. Never send it.
