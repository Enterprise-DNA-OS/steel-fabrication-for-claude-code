---
description: Render the paperwork: delivery dockets, payment claims and the manufacturer's data report, in the company's brand.
---

- Docket for a load: `npm run docs -- docket <load>`
- Payment claim: `npm run docs -- claim <claim number>`
- Manufacturer's data report (traceability, welding, inspections, NCRs) for a project: `npm run docs -- mdr <project>`
- Everything: `npm run docs`

Files land in `docs-out/`. Business name, logo and colours come from `brand.json`.
